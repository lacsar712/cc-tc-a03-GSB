# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。二衬龄期内洞温会拧偏测缝读数，后台下结论前必须先扣漂移：按测量员设置的系数与基准洞温、取洞温流水里最新一条当时洞温，算出扣漂后的毫米，再按绝对值是否不超过 3.0 mm 给出合格或超限。接口进程内后台线程认领待判行（不另起 worker 容器）。页面是 Svelte。

## 扣漂规则

- 公式：`扣漂后毫米 = 原始值 − 系数 ×（当时洞温 − 基准洞温）`
- 系数 0.05、洞温抬高 20℃ 时漂移 1.0 mm，扣漂后值与原始值差约 1 mm
- 判定看扣漂后值：仍在 ±3.0 mm 内判合格，抬到限外判超限
- 系数允许 0.001~0.5 mm/℃，洞温（含基准）允许 -20~60 ℃，越界提交退回并给人话提示
- 缺洞温（流水为空）或没设系数时提交同样退回

## 页面

页眉导航两个入口：

- **总表**：收敛记录列表（编号/桩号/收敛mm/状态/结论/说明）。测量员可「改数」修在线展示数字；改数不动补偿台账。系数不进总表格子。
- **补偿专页**（四块）：
  1. **系数设置**：补偿系数 + 基准洞温，仅测量员可改，巡检员只读；
  2. **洞温流水**：测量员登记当前洞温，提交测量时取最新一条；
  3. **补偿台账**：提交那一刻落账的原始值、当时洞温、系数、基准洞温、漂移量、扣漂后值与结论，事后改总表数字不影响这里，可单独翻旧账；
  4. **报送**：提交桩号 + 原始收敛值，进队记录和补偿账同一事务落库，拆开不齐判异常。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | 公开 | 登录拿 token |
| GET | `/api/logs` | 登录 | 总表列表 |
| POST | `/api/logs` | 测量员 | 报送：进队记录 + 补偿账同一事务落库 |
| PATCH | `/api/logs/<id>` | 测量员 | 只改在线展示数字，不动台账 |
| GET | `/api/compensation/settings` | 登录 | 查系数与基准洞温 |
| PUT | `/api/compensation/settings` | 测量员 | 改系数与基准洞温（越界退回） |
| GET | `/api/compensation/temps` | 登录 | 洞温流水 |
| POST | `/api/compensation/temps` | 测量员 | 登记洞温 |
| GET | `/api/compensation/ledger` | 登录 | 补偿台账 |

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
