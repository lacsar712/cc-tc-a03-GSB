# 隧道收敛测缝台

二衬龄期内洞温会把测缝读数拧偏，下结论前必须先扣漂移。测量员在**温度补偿专页**填温度系数、基准洞温、当时洞温与原始读数，进队记录与补偿账同一事务提交；接口进程内后台线程认领待判行，用提交时记下的洞温快照算扣漂后毫米，再按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 温度补偿

- 公式：`漂移 = k × (当时洞温 − 基准洞温)`，`扣漂后毫米 = 原始读数 − 漂移`
- 判定：扣漂后毫米绝对值 `≤ 3.0 mm` 为合格，否则超限
- 温度系数只接受 `0 < k ≤ 0.20 mm/℃`（常用 0.05：洞温抬高 20℃ 约扣 1 mm）；洞温接受 -20～60℃
- 缺洞温、缺系数或越界：提交整单退回，返回说人话的原因，库里不留半截记录
- 原始值与扣漂后值都进补偿账；补偿账与进队记录同生共死（单事务），不可改
- 在线展示数字可事后改（仅测量员），每次修改留痕；补偿账里当时记下的旧值永远单独可翻
- 巡检员可翻总表与补偿账流水，不能报送、不能改系数、不能改展示

页面从页眉进入：**总表**（原始/扣漂后/在线展示分列，系数不进总表）与**温度补偿专页**（①系数 ②洞温 ③流水 ④报送，四块）。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | 公开 | 登录换 JWT |
| GET | `/api/logs` | 登录 | 总表：原始/扣漂后/在线展示/改数留痕 |
| POST | `/api/logs` | 测量员 | 原子报送：`chainage, delta_mm, coeff_k, baseline_temp_c, measured_temp_c` |
| PUT | `/api/logs/<id>/display` | 测量员 | 只改在线展示值并留痕，不动账 |
| GET | `/api/ledger` | 登录 | 补偿账流水（系数/双洞温/原始/漂移/扣漂后） |
